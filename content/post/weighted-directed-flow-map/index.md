## どんなツールか？

都道府県間の人口移動や、国と国の輸出入のように、「どこからどこへ、どれだけ流れたか」を地図上の矢印で描くツールです。太さで量を、矢尻で向きを表します。

A→B と B→A で値が違うとき（例：大阪→東京は 26,284 人、東京→大阪は 20,207 人）も、2本の矢印を左右に並べて描くので、それぞれの量と向きを読み分けられます。往復を1本のリボンにまとめて、両端の太さで比べる描き方も選べます。

世界地図と日本地図（都道府県）を内蔵しています。都道府県名・国名・主要都市名は自動で地図上に配置され、それ以外の地点は緯度・経度で指定できます。

## 機能

- 入力形式: エッジリスト（出発地・到着地・値）と OD 行列（移動表）を自動判定
- 地点の配置: 都道府県名・国名・主要都市名を内蔵の地名辞書で自動配置。緯度経度の列でも指定できる。照合できなかった地名は一覧で確認できる
- ベースマップ: 世界・日本（都道府県）・なし。投影法、中心経度（データから自動）、表示範囲、九州より南の島を左上の枠に移す表示
- 往復の並べ方: 2本に分けて並べる（二車線）／1本にまとめる（両端の太さ＝各方向の値）
- 向きの表現: 均一幅＋矢尻、先細り、先細り＋矢尻、先細り＋中央矢印線
- 色: 単色、値の大小、往復の差、出発地別、到着地別。地点は純流入（流入超過・流出超過）で塗り分け
- 公開操作: 地点の絞り込み（流出／流入／両方）、総量／純量の切替、年などの分類の切替、拡大・縮小
- エクスポート: SVG / PNG / CSV / JSON
- シェア: 保存済みプロジェクトから公開ページ（`share.html?id=`）と埋め込みコードを発行
- プロジェクト保存: データと設定をクラウドに保存・復元

## 使い方

1. CSV / TSV / JSON をアップロードするか、サンプルデータから読み込む
2. マッピングで出発地・到着地・値の列と、地点の照合結果を確認する
3. スタイルでベースマップ、往復の並べ方、向きの表現、太さや色を調整する
4. 注釈タブでタイトル・出典・単位を入れる
5. 画像で書き出すか、プロジェクトとして保存し、必要なら公開シェアする

## データ形式

- ファイル形式: CSV / TSV / JSON
- エッジリスト: 1行が1本の流れ。出発地、到着地、値の列（`from` / `to` / `value`、`出発地` / `到着地` / `人数` なども可）。年などの分類列があれば、閲覧者が切り替えられる
- OD 行列: 先頭列が出発地、2列目以降の見出しが到着地、セルが流れの量
- 地名辞書にない地点は、`from_lat` / `from_lon` / `to_lat` / `to_lon` などの緯度経度列で指定する
- サンプル: 住民基本台帳人口移動報告（2025年）の都道府県間移動者数、財務省貿易統計の国別輸出入（2021〜2025年）
