## どんなツールか？

行ラベル × 列ラベル、セルが交差の値、というクロス集計表をそのまま可視化するツールです。リスト形式（行・列・値の3列）への変換は不要です。ヒートマップ、モザイク、積み上げバー、パラレル・コーディネイト、散布図行列、コード・ダイアグラム、隣接行列の7種から選べます。注釈、書き出し、プロジェクト保存、公開シェアに対応しています。

## 機能

- チャート選択: ヒートマップ、モザイク、積み上げバー、パラレル・コーディネイト、散布図行列、コード・ダイアグラム、隣接行列
- サンプル読込: 長方形のクロス集計と、行と列が同じ正方形行列をチャート種別に合わせて選べる
- マッピング: 行ラベルと値の列を指定。合計行・列は除外できる。長方形のチャートは向き（行をグループにする／列をグループにする）を切り替えられる
- 見た目: 配色、値の表示、積み上げ方式、0を中心にした配色
- 公開操作: パラレル・コーディネイトと散布図行列のブラシをリセット。隣接行列の並び替え（名前 / 頻度 / クラスタ）
- エクスポート: SVG / PNG
- シェア: 保存済みプロジェクトから公開ページ（`share.html?id=`）を発行
- プロジェクト保存: データと設定をクラウドに保存・復元

## 使い方

1. チャート種別を選ぶ（またはサンプルが開く）
2. CSV / TSV / JSON をアップロードするか、サンプルから読み込む
3. マッピングで行ラベルと値の列を確認する
4. 注釈タブでタイトルと出典を入れる
5. 画像で書き出すか、プロジェクトとして保存し、必要なら公開シェアする

## データ形式

- ファイル形式: CSV / TSV / JSON
- 先頭列が行ラベル、2列目以降が列ラベル。セルは交差の値
- リスト形式（行・列・値の3列）にはしない
- 行と列が同じ集合なら正方形（移動表・隣接行列）。任意で `group` 列を置けばクラスタに使う
