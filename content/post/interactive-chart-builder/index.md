## どんなツールか？

テンプレートを選んでデータを読み込むだけで、ホバーやアニメーションに反応するインタラクティブなチャートを作れるツールです。ストリームグラフ、バンプ・チャート、ビースウォーム・プロット、ベン図 / オイラー図、時系列散布図、サークル・パッキングの6種を用意しています。注釈、書き出し、プロジェクト保存、公開シェアに対応しています。

## 機能

- テンプレート: ストリームグラフ、バンプ・チャート、ビースウォーム・プロット、ベン図 / オイラー図、時系列散布図、サークル・パッキング
- サンプル読込: チャートごとに対応するサンプルデータを選べる
- マッピング: 軸、系列、サイズ、色に使う列を指定
- 見た目: 配色、曲線の種類、積み上げ方式、点や円の大きさなど
- 公開操作: 時系列散布図の再生・年の切り替え、ビースウォームの軸切り替え、ベン図の領域 / 和集合の切り替え、バンプ・チャートの系列の強調など
- 注釈: タイトル、出典、凡例の位置
- エクスポート: SVG / PNG / CSV / JSON
- シェア: 保存済みプロジェクトから公開ページ（`share.html?id=`）を発行。iframe で埋め込める
- プロジェクト保存: データと設定をクラウドに保存・復元

## 使い方

1. 一覧からテンプレートを選ぶ（サンプルが開く）
2. CSV / JSON をアップロードするか、サンプルから読み込む
3. マッピングで使う列を確認する
4. 注釈タブでタイトルと出典を入れる
5. 画像で書き出すか、プロジェクトとして保存し、必要なら公開シェアする

## データ形式

- ファイル形式: CSV / JSON
- ストリームグラフ・バンプ・チャート: 時間列＋系列ごとの列（ワイド形式）、または 時間 / カテゴリ / 値 の3列（ロング形式）
- ビースウォーム・プロット: 数値の列と、色分けに使うカテゴリの列
- 時系列散布図: `country` 列と `year` 列、X軸・Y軸に使う数値の列
- サークル・パッキング: 名前を表す列と数値の列
- ベン図 / オイラー図: ファイルは使わず、画面上で集合の名前とサイズを編集する
