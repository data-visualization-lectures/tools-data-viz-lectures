## どんなツールか？

カテゴリ変数の組み合わせと件数を、平行な軸のあいだを流れる帯（リボン）として描くツールです。パラレル・コーディネイトが数値の折れ線なのに対し、こちらはテキストや分類の頻度を面で表現します。色分けした軸を手がかりに、どの組み合わせが多いか、どこで分かれるかを追えます。注釈、書き出し、プロジェクト保存、公開シェアに対応しています。

## 機能

- マッピング: 値の列（件数など）と、2つ以上の次元（カテゴリ列）を指定。値列が無ければ行数を数えられる
- 色分け: 選んだ次元の値でリボンを着色
- カテゴリ順: 値の大きい順、A-Z、入力順
- 見た目: パレット、横／縦の向き、曲線の強さ、リボンの不透明度、バー幅。リボン・値・割合の表示切替
- 最大カテゴリ数: 軸あたりの表示数を制限し、残りは「その他」にまとめる
- エクスポート: 画像は SVG / PNG、データは CSV / JSON
- シェア: 保存済みプロジェクトから公開ページ（`share.html?id=`）を発行
- プロジェクト保存: データと設定をクラウドに保存・復元

## 使い方

1. CSV をアップロードするか、サンプルから読み込む
2. マッピングで値の列と次元を確認する
3. 色分けとカテゴリ順、スタイルで見た目を整える
4. 注釈タブでタイトルと出典を入れる
5. 画像で書き出すか、プロジェクトとして保存し、必要なら公開シェアする

## データ形式

- ファイル形式: CSV
- 1行目がヘッダー、2行目以降がデータ
- カテゴリ列を2つ以上置く。件数などの数値列があれば値に使う
- 例: クラス, 性別, 年齢, 生存, 件数
