Outputs and public projects created with Data Toolbox may be used in papers, conference presentations, teaching materials, reports, books, and websites. For research use, cite the tool name, URL, and access date.

## Basic Citation Format

```text
Data Toolbox, "<Tool name>", <tool URL>, accessed YYYY-MM-DD.
```

Example:

```text
Data Toolbox, "Kepler.gl", https://www.dataviz.jp/kepler-gl/, accessed 2026-07-03.
```

For public projects or shared pages:

```text
Public project created with Data Toolbox "<Tool name>", <public URL>, accessed YYYY-MM-DD.
```

## Open Source Credits

Some tools are based on open-source software. If your paper or report needs precise attribution, cite the underlying open-source project separately from Data Toolbox.

See the <a href="/en/license/">License</a> page for major open-source credits.

## Output Format Labels

Tool pages list only output formats that have been verified in the current implementation. Unverified formats are treated as "to be confirmed" and are not advertised as supported.

| Label | Meaning |
|---|---|
| SVG / vector | Editable in tools such as Illustrator and suitable for publication figures |
| PNG / image | Easy to use in slides, websites, and reports |
| CSV / TSV / GeoJSON / JSON | Reusable processed data or settings |
| Project save | A saved state that can be reopened later |
| Public URL / share URL | A URL that can be reviewed or shared for collaboration and teaching |
| Embed | Output suitable for websites, teaching pages, or articles |

## Notes

- Users are responsible for the content and interpretation of their figures and analyses.
- Check the license, privacy, and confidentiality requirements of the source data you use.
- Only include data that may be made public when using public URLs.
- Tool-specific output formats will be added to tool pages after implementation-level verification.
